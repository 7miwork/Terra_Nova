# Werkzeuge

Die Entwicklungshilfen liegen hier:

- `bilder_erzeugen.py` erzeugt Platzhalter für Gebäude in `bilder/gebaeude/`.
- `sounds_erzeugen.py` erzeugt WAV-Dateien in `audio/`.

Die Skripte werden nur zum Erzeugen oder Anpassen von Medien benötigt.
Sie gehören nicht zu den laufenden Spielmodulen in `spielmodule/`.
