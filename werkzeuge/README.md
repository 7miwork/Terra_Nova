# Beispielordner: Werkzeuge

Hier liegen Python-Skripte, die bei der Entwicklung helfen, aber nicht direkt
zum Spielen benoetigt werden, zum Beispiel `bilder_erzeugen.py` und
`sounds_erzeugen.py`.

Dieser Ordner zeigt den Unterschied zwischen Werkzeugen fuer die Entwicklung
und Python-Modulen, die Spielfunktionen umsetzen. Die Skripte bleiben hier;
es sollen keine Dateien verschoben werden.
