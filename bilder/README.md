# Bilder

Alle Spielgrafiken liegen in Unterordnern:

- `gebaeude/` für Gebäude
- `strasse/` für Straßen
- `terrain/` für Bodenbilder
- `items/` für Ressourcen und Gegenstände

Die Unterordner halten zusammengehörige Dateien übersichtlich zusammen.
Die Python-Module laden die Grafiken über `spielmodule/pfade.py`.
