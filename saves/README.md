# Spielstände und persönliche Daten

Hier liegen JSON-Dateien, die das Spiel selbst erstellt oder aktualisiert:

- `spielstand.json` für gespeicherte Partien
- `einstellungen.json` für Lautstärke, FPS und weitere Einstellungen
- `statistik.json` für dauerhafte Spielergebnisse

Die Dateien sind persönlich und werden von Git üblicherweise ignoriert.
`spielmodule/pfade.py` legt den Pfad zentral fest; die Dateien müssen nicht
im Projektordner liegen.
